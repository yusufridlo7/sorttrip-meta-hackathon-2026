# Dependency boundary and rights

The existing SortTrip platform and its Git history are not part of this repository. The setup script fetches the specifically identified baseline from the owner's separate repository into ignored local storage. Attribution and rights for that foundation and its assets remain applicable; this MIT license does not override them.

The new React components refer to existing React, lucide-react and foundation UI components. These dependencies and their license notices are resolved from the baseline's lockfile during installation. They are not vendored here. Brand icons used by the integrated UI come from the separate existing foundation; no logo bitmap, destination photograph or personal media is included in this package.

Integration edits include only event insertions/deletion counts and hashes, not a copy of the full old files. Added modules and their offline tests are listed in contributions.json. Historical commit dates alone do not establish authorship; the owner must review the contribution inventory and confirm event-period provenance before publication.
